Introdução ao HTML

HTML (HyperText Markup Language) é a linguagem de marcação utilizada para criar páginas web.

Estrutura do documento HTML

O documento HTML é composto por tags, que definem a estrutura e o conteúdo da página.

  • Principais tags do HTML:
    1. <h1> a <h6> : Tags de cabeçalho, usado para títulos e subtítulos.
    2. <p> : Tag de parágrafo, usada para texto corrido.
    3. <img> : Tag de imagem, usada para inserir imagens na página.
    4. <a> : Tag de link, usada para criar hyperlinks.
