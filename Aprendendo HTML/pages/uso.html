Tags HTML

As tags HTML são os elementos básicos que compõem a estrutura de uma página web.Elas são usadas para definir o conteúdo e a formatação da página.
A seguir, estão algumas das principais tags HTML e suas descrições:

Tag Descrição
H1 a H6 São tags de cabeçalho, usadas para títulos e subtítulos. Possui grais hierárquicos distintos, sendo o <h1> o mais importante e o <h6> o menos relevante.
<p> Tag de parágrafo, usada para texto corrido.
<img> Tag para inserir imagens no documento.
<a> Tag de link, usada para criar hyperlinks para outras páginas ou recursos.
<ul> Tag de lista não ordenada, usada para criar listas de itens.
<ol> Tag de lista ordenada, usada para criar listas de itens em ordem.
<li> Tag de item de lista, usada para criar itens dentro de listas.
Essas são apenas algumas das muitas tags disponíveis no HTML. Cada tag tem uma função específica e pode ser combinada com outras para criar páginas web complexas e interativas.

Exemplos de uso de cada tag

  • Exemplo de uso da tag <h1> a <h6>:

                        <h1>Título Principal</h1>
                    <h2>Título Secundário</h2>
                    <h3>Título Terciário</h3>
                    <h4>Título Quaternário</h4>
                    <h5>Título Quintanário</h5>
                    <h6>Título Sextanário</h6>

    As tags de cabeçalho em HTML, que vão de <h1> até <h6>, são utilizadas para definir títulos e subtítulos dentro de uma página. Elas seguem uma hierarquia de importância, sendo <h1> o nível mais alto e o<h6>o mais baixo. Isso significa que o<h1> geralmente representa o título principal da página, enquanto as demais tags são usadas para organizar o conteúdo em seções e subseções, tornando a estrutura mais clara e compreensível.

    Além de influenciarem a organização visual do conteúdo, essas tags também têm grande importância para a semântica da página. Os mecanismos de busca utilizam essa hierarquia para entender melhor o conteúdo do site, o que impacta diretamente em SEO (otimização para motores de busca). Da mesma forma, leitores de tela usados por pessoas com deficiência visual dependem dessa estrutura para navegar pelo conteúdo de forma eficiente, o que torna o uso correto das tags essencial para acessibilidade.

    É importante utilizar as tags de forma lógica e consistente, respeitando a ordem hierárquica — ou seja, evitando pular níveis sem necessidade, como ir de o<h1> diretamente para o<h4>. Embora seja possível estilizar qualquer cabeçalho com CSS, o significado semântico dessas tags deve ser mantido. Dessa forma, garante-se não apenas uma boa apresentação visual, mas também uma melhor organização, acessibilidade e desempenho nos mecanismos de busca.

  • Exemplo de uso da tag <p>:

                        <p>Este é um parágrafo.</p>

    A tag <p> em HTML é utilizada para definir parágrafos de texto em uma página.
    Ela é uma das tags mais básicas e importantes para a estruturação de conteúdo, pois permite organizar textos longos em blocos separados, facilitando a leitura.
    Sempre que há uma nova ideia ou parte do conteúdo que precisa ser destacada como um bloco independente, utiliza-se a tag <p>.

    Além de organizar o conteúdo visualmente, a tag <p> também possui significado semântico, indicando aos navegadores e mecanismos de busca que aquele trecho corresponde a um parágrafo.
    Isso contribui para a acessibilidade, já que leitores de tela conseguem interpretar melhor a divisão do texto, oferecendo uma navegação mais clara para usuários com deficiência visual.
    Por padrão, os navegadores aplicam espaçamento antes e depois de cada <p>, o que ajuda a diferenciar os blocos de texto sem necessidade de estilização adicional.

    É importante usar a tag <p> corretamente, evitando colocá-la dentro de elementos que não permitem esse tipo de conteúdo ou utilizá-la para fins puramente visuais, como criar espaços na página.
    Para ajustes de aparência, o ideal é utilizar CSS.
    Dessa forma, o código permanece organizado, semântico e mais fácil de manter, garantindo uma melhor experiência tanto para usuários quanto para desenvolvedores.

  • Exemplo de uso da tag <img>:

                        <img src="caminho/para/imagem.jpg" alt="Descrição da imagem">

    A tag <img> em HTML é utilizada para inserir imagens em uma página web.
    Diferente de outras tags, ela não possui conteúdo de fechamento, sendo considerada uma tag vazia (ou self-closing).
    Para funcionar corretamente, é necessário utilizar o atributo src, que indica o caminho da imagem, seja ele um arquivo local ou uma URL.
    Dessa forma, a imagem é carregada e exibida diretamente no local onde a tag foi inserida no código.

    Outro atributo essencial da tag <img> é o alt, que fornece um texto alternativo para a imagem.
    Esse atributo é extremamente importante para acessibilidade, pois permite que leitores de tela descrevam a imagem para pessoas com deficiência visual.
    Além disso, o alt também é exibido caso a imagem não seja carregada, ajudando o usuário a entender o conteúdo que deveria estar ali.
    O uso adequado desse atributo também contribui para o SEO, pois mecanismos de busca utilizam essas descrições para indexar melhor o conteúdo da página.

    Além de src e alt, a tag <img> pode incluir outros atributos, como width e height, que definem as dimensões da imagem, e title, que exibe um texto ao passar o mouse sobre ela.
    No entanto, para manter uma boa prática de desenvolvimento, recomenda-se controlar a aparência da imagem com CSS, em vez de depender apenas de atributos HTML.
    Assim, o código fica mais organizado, flexível e alinhado com os padrões modernos de desenvolvimento web.

  • Exemplo de uso da tag <a>:

                        <a href="https://www.exemplo.com">Visite nosso site</a>

    A tag <a> em HTML, conhecida como “âncora”, é utilizada para criar links que permitem a navegação entre páginas ou partes de um mesmo documento.
    O principal atributo dessa tag é o href, que define o destino do link, podendo ser uma URL externa, um arquivo local ou até mesmo um identificador dentro da própria página.
    Ao clicar no conteúdo dentro da tag <a>, o usuário é direcionado para o endereço especificado.

    Além do href, a tag <a> pode conter outros atributos importantes, como o target, que define como o link será aberto.
    Por exemplo, o valor _blank faz com que o link seja aberto em uma nova aba do navegador.
    Também é possível usar a tag para criar links de e-mail (com mailto:) ou para números de telefone (com tel:), ampliando suas possibilidades de uso.
    Isso torna a <a> uma das tags mais versáteis para interação e navegação na web.

    É importante utilizar a tag <a> de forma clara e acessível, garantindo que o texto do link descreva bem o destino, em vez de usar expressões genéricas como “clique aqui”.
    Isso melhora a experiência do usuário e também a acessibilidade, já que leitores de tela utilizam o texto do link para orientar a navegação.
    Além disso, boas práticas de uso contribuem para o SEO e para a organização geral do conteúdo da página.

  • Exemplo de uso da tag <ul> e <li>:

                        <ul>
                        <li>Item 1</li>
                        <li>Item 2</li>
                        <li>Item 3</li>
                    </ul>

    As tags <ul> e <li> em HTML são utilizadas em conjunto para criar listas não ordenadas, ou seja, listas em que a ordem dos itens não é relevante.
    A tag <ul> (unordered list) define o contêiner da lista, enquanto a tag <li> (list item) representa cada item dentro dessa lista.
    Por padrão, os navegadores exibem listas <ul> com marcadores (geralmente bolinhas) antes de cada item.

    Essas tags são muito úteis para organizar informações de forma clara e estruturada, como menus de navegação, listas de tarefas, tópicos ou características de um produto.
    Cada elemento <li> pode conter não apenas texto, mas também outros elementos HTML, como links, imagens ou até mesmo outras listas, permitindo a criação de estruturas mais complexas, como listas aninhadas.

    Além do aspecto visual, o uso correto de <ul> e <li> também contribui para a semântica da página e para a acessibilidade.
    Leitores de tela conseguem identificar que se trata de uma lista e informar ao usuário quantos itens ela possui, melhorando a navegação.
    Para alterar a aparência da lista, como remover os marcadores ou modificar o estilo, recomenda-se utilizar CSS, mantendo o HTML limpo e bem estruturado.

  • Exemplo de uso da tag <ol> e <li>:

                        <ol>
                        <li>Primeiro item</li>
                        <li>Segundo item</li>
                        <li>Terceiro item</li>
                    </ol>

    As tags <ol> e <li> em HTML são utilizadas para criar listas ordenadas, ou seja, listas em que a sequência dos itens é importante.
    A tag <ol> (ordered list) define o contêiner da lista, enquanto a tag <li> (list item) representa cada elemento dentro dela.
    Por padrão, os navegadores exibem os itens numerados, indicando claramente a ordem em que devem ser seguidos.

    Esse tipo de lista é muito útil em situações como passo a passo de instruções, receitas, rankings ou qualquer conteúdo que dependa de uma sequência lógica.
    Assim como nas listas não ordenadas, cada <li> pode conter diferentes tipos de conteúdo, como textos, links, imagens ou até mesmo outras listas, permitindo a criação de estruturas mais completas e organizadas.

    Além de melhorar a organização visual, o uso de <ol> e <li> também contribui para a semântica e acessibilidade da página.
    Leitores de tela conseguem interpretar a lista como ordenada e informar a posição de cada item ao usuário.
    Caso seja necessário alterar o tipo de numeração (como letras ou números romanos), isso pode ser feito com atributos HTML ou, preferencialmente, com CSS, mantendo o código limpo e seguindo boas práticas de desenvolvimento.
