# 📁 Portfólio de Projetos Web — Arthur Linhares

Repositório com os projetos desenvolvidos ao longo do aprendizado de desenvolvimento front-end. Os projetos estão organizados em ordem cronológica e mostram uma evolução progressiva em HTML, CSS e JavaScript.

---

## 🗂️ Projetos

### 01 · Introdução ao HTML
> Material didático sobre as principais tags HTML

**Tecnologias:** HTML · CSS  
**Páginas:** `index.html` · `pages/uso.html`

Uma página educativa que apresenta as principais tags do HTML com exemplos práticos e uma tabela de referência. Conta com navegação interna por âncoras e imagem da estrutura básica de um documento HTML.

📌 **Conceitos aplicados:** listas, tabelas, links, imagens, âncoras internas

---

### 02 · Cantinho das Receitas
> Blog de receitas com múltiplas categorias

**Tecnologias:** HTML · CSS  
**Páginas:** index · café · almoço · jantar · sobremesas · blog · artigos

Blog multi-página de receitas culinárias organizado por categorias (café da manhã, almoço, jantar e sobremesas). Cada página contém receitas com ingredientes, modo de preparo e imagens dos pratos.

📌 **Conceitos aplicados:** estrutura multi-página, listas ordenadas e não-ordenadas, imagens, navegação

---

### 03 · Grand Prix — Site de Fórmula 1
> Fan page da F1 com pilotos, equipes e cadastro de torcedor

**Tecnologias:** HTML · CSS · JavaScript  
**Páginas:** index · pilotos · equipes · cadastro · sucesso

Site temático de Fórmula 1 com grid de pilotos da temporada 2026, tabela de equipes e construtores, e formulário de cadastro para torcedores. Primeiro projeto com JavaScript: cards interativos com toggle de informação via botão "Ler Mais".

📌 **Conceitos aplicados:** CSS por página, JavaScript para DOM (toggle), tabelas complexas, layout com cards, navegação consistente

---

### 04 · PetCare — Pet Shop Completo
> Site de pet shop com loja, carrinho e agendamentos

**Tecnologias:** HTML · CSS · JavaScript · Google Fonts  
**Páginas:** index · produtos/carrinho · agendamento banho · agendamento tosa · blog · confirmações

O projeto mais completo do portfólio. Inclui loja com carrinho de compras funcional (adicionar itens, calcular total, finalizar pedido via JavaScript), agendamento de banho e tosa com formulários detalhados, blog informativo com vídeos, e página de produtos com tabela de preços por categoria.

📌 **Conceitos aplicados:** JavaScript avançado (carrinho com localStorage, manipulação de DOM), CSS modular por seção, layout com grid e cards, múltiplos formulários, vídeo embutido
